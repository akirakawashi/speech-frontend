# Заглушка каталога `pages`

Здесь нет страниц, и появляться им не нужно. Каталог существует, чтобы Next.js
не принял за Pages Router слой `src/pages` из Feature-Sliced Design.

Next.js ищет `pages` сначала в корне проекта, потом в `src`. Найдя корневой
каталог, в `src/pages` он уже не заглядывает. Без этой заглушки сборка падает:
маршруты приложения лежат в корневом `app/`, а `pages` оказался бы в `src/` —
Next.js требует, чтобы оба были в одном месте.

Страницы приложения — в `src/pages/`, маршруты — в `app/`. Подробнее:
[docs/architecture.md](../docs/architecture.md).
